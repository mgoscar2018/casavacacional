# **App Name**: CasaVacacional

## Core Features:

- Image Carousel: Display a carousel of vacation home images.
- Thumbnail Navigation: Include a thumbnail navigation for the carousel.
- Manual Navigation: Provide 'next' and 'previous' buttons for manual navigation.
- Transition Animations: Implement animations for transitioning between carousel images. Implement animations and effects as shown in example.
- Auto Advance: Automatically advance the carousel images after a set interval.
- Progress Timer: Implement a progress bar to indicate the time until the next image transition.

## Style Guidelines:

- Primary color: Dark orange (#F1683A) to highlight key elements and call attention.
- Background color: Black (#000000) for a modern and sophisticated look.
- Accent color: Off-white (#EEEEEE) to ensure text readability against the dark background.
- Body and headline font: 'Poppins' (sans-serif) for a modern, clean aesthetic.
- Carousel width should take up nearly the entire screen, centered.
- Navigation thumbnails should be placed near the bottom of the carousel.
- Match thumbnail animation speed from example project
